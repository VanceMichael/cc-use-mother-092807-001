# 深层气井产能承诺与复产决策

管理深层气井测试、复产、检修、外输能力和供气承诺。

## 参与方与事实

主要参与方包括油气田生产调度人员、地质与储层人员、井队和维护团队、输气运行人员、供气计划人员。领域资料记录以下已经确认的事实：

- 西南油气田2026年油气当量突破3000万吨
- 多个深层和超深层区块出现百万方级测试产量
- 老井经大修和酸化解堵后恢复生产

## 业务约束

- 井与储层版本
- 测试到稳产转换
- 检修和外输约束
- 供气承诺
- 日报更正与追溯

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_001.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
