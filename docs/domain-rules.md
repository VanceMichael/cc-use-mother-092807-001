# 领域边界与业务规则

管理深层气井测试、复产、检修、外输能力和供气承诺。

## 领域对象关系

区块 1—N 井；井有只增不覆盖的储层解释版本与测试批次。
测试批次经独立复核后可登记产能声明；产能声明按
tested → trial → stable 演进，每次演进是更替（旧声明 superseded），
不是新增产量。井经路由接入外输通道；通道可在时间窗内被限输。
作业方案（大修/酸化解堵/压裂调整）与检修窗口在时间窗内阻断该井供应。
供气合同绑定交付通道；供气承诺按合同+供气日登记，落供气决定快照与
逐井安排；安排被日报定稿后转为 fulfilled 永久冻结。

## 硬性规则

1. 任何可用产能必须声明适用时间窗（valid_from ≤ valid_to）、置信等级
   （high/medium/low）与置信依据（测试制度、解释版本、复核记录）。
2. low 置信产能不计入可对承诺担保的可靠供应，仅作参考展示。
3. 同一井同一时刻至多一条 active 产能；同一测试批次/产能例外/被更替
   声明只能产生一条新产能，杜绝跨口径重复承诺。
4. 地质人员提交测试与产能例外，但不得复核/审批自己提交的内容；
   产能例外由调度审批。
5. 测井/生产回执按（编号, 内容哈希）幂等：同号同内容重复到达不累计；
   同号不同内容整组隔离，留痕全部变体，调度处置放行或丢弃后方可引用；
   已处置编号不得再被不同内容复用。
6. 作业/检修/限输/产能/路由事件只重算尚未履行的供气安排（供气日未到，
   或当日尚无日报且状态为 planned/revised；曾经取消的安排可在供应恢复时
   复活）；已形成的日报与决定只能通过更正版本衔接。
7. 已开工的作业不能改期；已生效的限输不能改期只能解除；检修窗口超过
   应解锁日仍持续阻断，直到维护/调度人工解锁。
8. 作业完工后旧产能口径失效（superseded），井须凭复产测试重新认定产能。
9. 日报定稿不可变；数值更正生成 version+1，经 corrects_id 链回旧版。
10. 供气决定每次重算生成新版本并保存完整快照，旧版 superseded 保留。
11. 同一交付通道、同一供气日的多个承诺共享能力池，按登记顺序分配；
    能力不足即开放承诺缺口提醒，供应恢复后自动消除，也可手工关闭。
12. 商业用户只能访问自己合同的供气信息，决定快照中无关通道/井数据脱敏。
13. 所有待办（待复核测试、待解锁检修、开放缺口、隔离材料、待审批例外）
    落盘持久化，系统重启后由 recover() 恢复。
14. 资料版本只能递增。示例数据不得包含真实个人信息、账号或凭据。

## 追溯

从供气日的合同供气数字出发，经供气安排可下钻到：井与当日井况、
生效产能及其血缘链（转正链 → 测试批次 → 储层解释版本 → 回执材料）、
当日作业/检修/限输决定与修订记录、供气决定各版本快照，以及提交人、
复核人、审批人、解锁人等责任人。
