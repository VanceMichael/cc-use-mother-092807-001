# 领域边界与规则

管理深层气井测试、复产、检修、外输能力和供气承诺。本文件是后端必须始终满足的规则清单，
实现见 `src/deep_gas/`，可执行验证见 `tests/` 与 `scripts/demo.py`。

## 关联对象

区块 → 井 → 储层解释版本；测试批次、作业方案（事件流）、设备检修锁、日产曲线、
外输通道（路由、限输窗口）、合同 → 供气承诺（供应组合、逐日提名）→ 供气决定（版本+证据）。

## 不可变与只追加

1. 资料、储层解释、产能口径、日报、供气决定的**版本只能递增**，历史行永不物理覆盖。
2. 测试→试采→稳产是**同一产能谱系的版本接替**，不是三笔新增产能：
   - 旧版本在新版本生效前一日收口；任一供气日至多命中一个有效版本；
   - 只允许逐级晋级（testing→trial→stable）；
   - 每个测试批次最多建立一条谱系；同井同层系不得建立生效日重叠的并行测试谱系；
   - 老井已有测试口径时，历史基线不再叠加。
3. 日报只追加更正版本（correction_of 引用前驱）；供气决定每次评估冻结新版本与证据快照。

## 适用时间与置信依据

4. 任何可用产能必须带 `valid_from/valid_to` 与置信度（low/medium/high）及文字依据；
   只有 high 计入 firm，medium/low 计入 conditional。
5. 维修停井、酸化解堵、压裂调整、管网限输、检修锁都以**生效窗口**表达，
   只改变窗口内尚未履行的安排；已形成的日报与供气决定不回改，差异由新版本衔接。
6. 复产/措施见效作为增量产能，以复产事件为唯一来源建立一条谱系；
   复产同时收口覆盖复产日的停井窗口（复产日当天井即恢复可用）。

## 来件去重与隔离

7. 回执编号全局唯一：编号与载荷均相同的重复件返回 duplicate，绝不再次累计。
8. 编号相同而数值不同：不覆盖台账、不参与累计，先入隔离区；仅调度可裁决
   采用（accept）或丢弃（discard）。

## 权限与数据范围

9. 地质（提交人本人或地质岗位）不能审批产能例外；审批必须来自调度/输气/计划等独立岗位；
   作业方案提出人不能审批自己的方案；检修锁仅维护部门可解除。
10. 商业用户只能读取被授权合同的供气决定与缺口，且不能执行任何内部写操作。

## 重启恢复与追溯

11. 待复核测试、待解除检修锁、开放的承诺缺口提醒、待独立审批例外、隔离材料均持久化，
    进程重启后由值班工作台继续呈现，直至被处置。
12. 任意供气日的供气数字必须可追溯到：逐井产能版本及置信依据、停阻原因（作业事件/检修锁）、
    通道限输/锁定证据、以及每个动作的责任人和岗位。

## 示例资料约束

参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据；
`fixtures/context.json` 中的人名均为虚构演示身份。
